# Support

## Questions and Usage Help

Use [GitHub Discussions](https://github.com/pulkitxm/quinjet/discussions) for
installation help, usage questions, ideas, and examples. Include the Quinjet
version, operating system, terminal, Git version, and the command you ran when
they are relevant.

The project is maintained on a best-effort basis. Response times are not
guaranteed, but clear reproductions and focused questions are easier to answer.

## Bugs and Feature Requests

Use the repository's issue forms for reproducible bugs and focused feature
requests. Search existing issues and discussions first, and remove credentials
or private repository contents from logs and screenshots.

## Security and Conduct

Report vulnerabilities through the process in [SECURITY.md](SECURITY.md), not
through an issue or discussion. Report community conduct concerns using the
private contact guidance in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
